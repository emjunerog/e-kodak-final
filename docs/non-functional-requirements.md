## Definitions of Non-Functional Requirements

### Hardware Requirements
* **NonFunc_001 - Personal Computer / Laptop:** Enables administrators and photographers to manage studio bookings, process photos, parse student masterlists, and configure system operations.
* **NonFunc_002 - Mobile Smartphone:** Enables clients and photographers to scan QR codes, monitor production milestones, view schedules, and access digital passes on portable devices.

### Software Requirements
* **NonFunc_003 - Operating System:** Provides the underlying environment to run web browsers, development tools, and mobile applications.
* **NonFunc_004 - React.js:** Powers the modular single-page web user interface with fast component rendering and state management.
* **NonFunc_005 - Tailwind CSS:** Provides responsive layout styling, visual themes, and adaptive screen formatting across devices.
* **NonFunc_006 - JavaScript:** Provides client-side logic, dynamic user interface behavior, and asynchronous communication with backend services.
* **NonFunc_007 - Vite:** Serves as the frontend development server and production build bundler.
* **NonFunc_008 - React Native / Expo:** Powers the cross-platform mobile companion application for Android and iOS devices.
* **NonFunc_009 - Supabase (PostgreSQL):** Provides relational data storage, user authentication, row-level security policies, and photo file storage.
* **NonFunc_010 - Netlify:** Provides automated cloud deployment, global content delivery, and web hosting infrastructure.
* **NonFunc_011 - Python (FastAPI / OR-Tools):** Provides backend optimization services for schedule validation and automated calendar allocation.
* **NonFunc_012 - Google Gemini API:** Provides automated responses to customer inquiries regarding studio packages, schedules, and policies.
* **NonFunc_013 - pdfjs-dist / jsPDF / docx:** Enables client-side extraction of student data from documents and generation of print-ready yearbook PDF files.
