# Table 6: Cause and Effect Analysis

This document presents the concise **Cause and Effect Analysis (Table 6)** for the **E-KODAK: Photography Service Management System with Real-Time Tracking**, replacing the analytics module with school masterlist and yearbook processing.

---

## Table 6
### Cause and Effect Analysis

| Problem and Opportunities | Cause and Effect | System Objectives | System Constraints |
|---|---|---|---|
| **Manual appointment and transaction management** | Physical logbooks cause scheduling conflicts, double bookings, lost receipts, and delayed workflows. | To automate appointment booking and transaction handling using a centralized database. | User adaptation from manual paper records to a digital web interface. |
| **Inefficient tracking of photo output statuses** | Manual tracking makes monitoring production stages difficult, resulting in delayed photo delivery. | To implement real-time QR code tracking and digital passes across all production milestones. | Requires camera-enabled mobile devices and consistent photographer scanning compliance. |
| **Inconsistent client communication and updates** | Lack of proactive order updates leads to repetitive inquiries and congested social media chats. | To provide automated status notifications and self-service digital pass tracking. | Requires active internet connectivity for real-time cloud data synchronization. |
| **Manual student masterlist and yearbook processing** | Manual re-encoding of student rosters causes typographical errors and significantly delays graduation yearbook publication. | To automate student roster parsing from documents and batch-link portraits for streamlined yearbook compilation. | Requires readable, standard document formats (PDF or Word) for accurate automated data extraction. |
