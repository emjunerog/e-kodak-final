# Table 1
## Functional Requirements

| Use Case | Description |
|---|---|
| **Use Case No. 001- REGISTER** | Enables clients to create an account using their personal and academic details. |
| **Use Case No. 002- LOGIN** | Enables users (Customer, Admin, Photographer) to authenticate securely and access their role-specific portal. |
| **Use Case No. 003- VIEW SERVICE PACKAGES & PRICING** | Enables users to browse photography services, package tiers, inclusions, and prices. |
| **Use Case No. 004- VIEW PORTFOLIO GALLERY** | Enables users to view categorized studio portfolio photos with an interactive preview modal. |
| **Use Case No. 005- ASK AI ASSISTANT FOR INQUIRIES** | Enables clients to ask questions and receive automated answers regarding packages and studio policies. |
| **Use Case No. 006- TRACK BOOKING VIA PUBLIC PASS** | Enables clients to check session progress using a booking reference number or public pass link. |
| **Use Case No. 007- BOOK PHOTO SESSION** | Enables clients to start a session booking by selecting packages and providing student information. |
| **Use Case No. 008- SELECT DATE & TIME SCHEDULE** | Enables clients to view open studio dates and select available session time slots. |
| **Use Case No. 009- REVIEW BOOKING SUMMARY** | Enables clients to review service inclusions, pricing breakdowns, and terms before checkout. |
| **Use Case No. 010- SUBMIT DOWNPAYMENT & BILLING** | Enables clients to submit downpayments via GCash, Maya, or bank transfer with reference verification. |
| **Use Case No. 011- GENERATE BOOKING QR PASS** | Enables the generation of a digital booking pass with a unique QR code upon reservation completion. |
| **Use Case No. 012- VIEW BOOKING DETAILS & DOSSIER** | Enables clients to view booking details, studio venue maps, and print session credential vouchers. |
| **Use Case No. 013- TRACK PHOTO PRODUCTION STATUS** | Enables users to track real-time milestone progress from booking received to ready for pickup. |
| **Use Case No. 014- VIEW & DOWNLOAD SOFT COPIES** | Enables clients to view watermarked proofs and download released high-resolution digital photos. |
| **Use Case No. 015- CANCEL OR RESCHEDULE BOOKING** | Enables clients to request session rescheduling or cancel reservations according to studio policies. |
| **Use Case No. 016- SCAN QR CODE IN MOBILE APP** | Enables users to scan booking QR codes using the mobile app camera to retrieve session details. |
| **Use Case No. 017- TRACK MILESTONES ON MOBILE** | Enables mobile users to monitor real-time production stages guided by interactive studio mascots. |
| **Use Case No. 018- SAVE BOOKINGS FOR OFFLINE ACCESS** | Enables mobile users to cache and view their session details without an active internet connection. |
| **Use Case No. 019- MANAGE PHOTOGRAPHER AVAILABILITY** | Enables photographers to configure working schedules and block off-duty calendar dates. |
| **Use Case No. 020- VIEW ASSIGNED SHOOT ROSTER** | Enables photographers to view their schedule of assigned shoots, client briefs, and session details. |
| **Use Case No. 021- UPLOAD PHOTO DELIVERABLES** | Enables photographers to upload captured photo sets by booking directly to the studio vault. |
| **Use Case No. 022- UPLOAD SCHOOL MASTERLIST** | Enables clients or the admin to upload class section rosters in PDF or document format. |
| **Use Case No. 023- SCAN & PARSE MASTERLIST** | Enables automated extraction of student names, ID numbers, sections, packages, and mottos from documents. |
| **Use Case No. 024- MANAGE SCHOOL MASTERLISTS** | Enables the admin to view, edit, and organize uploaded student section rosters. |
| **Use Case No. 025- MANAGE YEARBOOK PROJECTS** | Enables the admin to create and configure academic yearbook publication projects. |
| **Use Case No. 026- MANAGE YEARBOOK PAGE LAYOUTS** | Enables the admin to select and configure yearbook page templates and design themes. |
| **Use Case No. 027- BATCH UPLOAD YEARBOOK PORTRAITS** | Enables the admin to batch upload and link individual 2x2 graduation portraits to student records. |
| **Use Case No. 028- VIEW YEARBOOK FLIPBOOK** | Enables users to preview compiled yearbook pages in an interactive 3D digital flipbook format. |
| **Use Case No. 029- EXPORT YEARBOOK (PDF/PRINT)** | Enables the admin to run preflight completeness checks and export print-ready yearbook PDF files. |
| **Use Case No. 030- VIEW ANALYTICAL DASHBOARD** | Enables the admin to view real-time studio KPIs, booking volumes, and revenue metrics. |
| **Use Case No. 031- MANAGE BOOKINGS & ASSIGNMENTS** | Enables the admin to update booking milestones, manage walk-in orders, and assign photographers. |
| **Use Case No. 032- MANAGE CUSTOMER DIRECTORY** | Enables the admin to search client academic profiles and monitor live portal presence. |
| **Use Case No. 033- VERIFY PAYMENTS & RECORD TREASURY** | Enables the admin to verify payment proofs, record cash receipts, and issue printable vouchers. |
| **Use Case No. 034- MANAGE SERVICES & ADD-ONS** | Enables the admin to configure service categories, package tiers, inclusions, and add-on pricing. |
| **Use Case No. 035- MANAGE STUDIO SETTINGS & CMS** | Enables the admin to configure operating hours, payment QR codes, policies, and landing page notices. |
| **Use Case No. 036- LOGOUT** | Enables users to terminate their active session securely and clear authentication tokens. |
